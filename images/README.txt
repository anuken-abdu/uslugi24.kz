ФОТОГРАФИИ ДЛЯ САЙТА uslugi24.kz
Положите файлы в эту папку с точно такими именами. Формат WebP (JPG тоже можно, но тогда переименуйте в коде).
Пока фото нет, на их месте показывается аккуратная заглушка — сайт выглядит законченным и без них.

hero.webp              — главное фото (вертикальное 4:5), 960×1200. Мастер за работой в квартире, без логотипов чужих компаний.
mebel.webp             — сборка мебели, 800×500 (16:10)
plotnik.webp           — установка/плотницкие работы (телевизор на стене, ламинат, карниз), 800×500
santehnika.webp        — сантехника (смеситель, раковина), 800×500
elektrika.webp         — электрика (розетка, люстра), 800×500
remont.webp            — мелкий ремонт (инструмент, перфоратор), 800×500
og.jpg                 — превью для мессенджеров и соцсетей, 1200×630
apple-touch-icon.png   — иконка для iPhone, 180×180

Рекомендации по весу: hero до 180 КБ, остальные до 90 КБ. Реальные фото работ мастеров лучше стоковых.

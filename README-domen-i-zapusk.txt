УСЛУГИ 24 — запуск нового сайта на домене uslugi-24.kz (Vercel)

1. VERCEL
   • Новый проект → загрузите эту папку целиком (или через GitHub). Сборка в vercel.json: python3 src/build.py → dist/. В логе сборки должно быть «pages: 56».
   • Settings → Environment Variables: ANTHROPIC_API_KEY — для ИИ-консультанта (без ключа работает встроенный автоответчик).
   • Settings → Domains: добавьте www.uslugi-24.kz (основной) и uslugi-24.kz (редирект на www).

2. DNS НОВОГО ДОМЕНА uslugi-24.kz (у регистратора, где куплен домен)
   • A-запись   uslugi-24.kz.      → 76.76.21.21
   • CNAME      www.uslugi-24.kz.  → cname.vercel-dns.com.
   • Другие A/AAAA-записи для @ и www (парковка регистратора) — удалить.
   Через 15 минут – несколько часов в Vercel → Domains появится «Valid Configuration», SSL выпустится сам.

3. СТАРЫЙ ДОМЕН uslugi24.kz (без дефиса) — чтобы не потерять позиции в Google
   Лучший вариант — 301-редирект со старого домена на новый (страница к странице не нужна, главная → главная):
   • Вариант А (проще всего): добавьте uslugi24.kz и www.uslugi24.kz в тот же проект Vercel → Domains → у каждого «Redirect to www.uslugi-24.kz» (301). DNS старого домена: A @ → 76.76.21.21, CNAME www → cname.vercel-dns.com, AAAA-записи удалить.
   • Вариант Б: оставить в Plesk и включить там переадресацию 301 на https://www.uslugi-24.kz/.
   • Перед переключением сделайте бэкап WordPress в Plesk (Сайты и домены → WordPress → Резервное копирование).
   • MX, mail, TXT (SPF/DKIM) на старом домене НЕ трогать, если на нём есть почта.

4. ПОСЛЕ ЗАПУСКА
   • Google Search Console: добавьте ресурс https://www.uslugi-24.kz/ и отправьте sitemap.xml. Если старый домен тоже подтверждён в Search Console — «Настройки → Смена адреса» на новый.
   • Google Business Profile (карточка на Картах): поменяйте сайт на https://www.uslugi-24.kz/.
   • 2ГИС, Instagram, WhatsApp Business — тоже обновите ссылку на сайт.

ТЕГИ GOOGLE: ID тегов (GTM/AW) и метки конверсий вписываются в src/data.py (TAG_ID и др.) — они ставятся в <head> каждой страницы.
ОБНОВЛЕНИЯ: меняются только файлы src/, assets/, api/ — dist/ Vercel собирает сам.
GOOGLE ADS: файлы в google-ads/ загружаются по порядку 0→5 (Инструменты → Массовые действия → Загрузки). Список минус-слов «Услуги24 минус-слова» сначала создайте вручную (Инструменты → Общая библиотека → Списки исключений → Списки минус-слов), потом файлы 4 и 5. Настройки — в 6-teksty-i-nastroyki.txt.
